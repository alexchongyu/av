### 1.3 Linux (alexws, 192.168.2.2) — 오프라인 빌드
전체 절차: 리포 루트 **`linux-compile-install.md`** 참조. 요약:
```bash
bash script/sync-linux.sh                    # Mac→192.168.2.2:/user/alex/claude_code/av (rsync)
ssh -o ClearAllForwardings=yes 192.168.2.2 'bash -l' <<'EOF'
cd /user/alex/claude_code/av

bash script/bundle-av.sh                      # bin/av-bundle/ 생성
rsync -a --delete bin/av-bundle/ /user/alex/local/bin/av-bundle/
ln -sfn /user/alex/local/bin/av-bundle/av /user/alex/local/bin/av   # ★ PATH 노출(없으면 av 명령이 옛것 잡음)
EOF
```
- **⚠⚠ 시계-오차 함정 (이번 세션 대형 삽질, 반드시 기억)**: alexws 시계가 Mac보다 ~6분 느려서
  rsync 한 소스가 "미래" mtime → `ninja: manifest 'build.ninja' still dirty ... system time`.
  - **고정 과거일 touch(`touch -t 202607200000`) 금지** — 소스가 .o보다 과거가 되어 **ninja 가 재컴파일을 스킵**,
    버전 문자열만 새것/코드는 옛것이 됨(→ 리눅스만 옛 동작으로 오진).
  - **올바른 우회**: 인자 없는 `find . -not -path './.git/*' -exec touch {} +` (=박스 현재시각) **또는**
    `rm -rf build/CMakeFiles/av.dir && ninja -C build` (강제 재컴파일).
  - **검증**: 버전 문자열 말고 **ninja 출력에 소스 컴파일 라인이 실제로 있는지** 확인.
  - 근본해결: `sudo timedatectl set-ntp true` (sudo 필요, 미실행).

### 1.4 Windows (Demura, 192.168.2.241) — VS2022/ClangCL, WSL 경유
스크립트: `script/sync-win.sh`, `script/win-build-wsl.sh [all|deps|configure|build]`.
```bash
bash script/sync-win.sh                       # Mac→241:/mnt/c/Users/Alex/claude_code/av
ssh 192.168.2.241 'bash -lc "cd /mnt/c/Users/Alex/claude_code/av && rm -f build.log && nohup bash script/win-build-wsl.sh all > build.log 2>&1 & echo PID=\$!"'
# 폴링: ssh 192.168.2.241 'bash -lc "cd /mnt/c/Users/Alex/claude_code/av; tail build.log"'
```
- **C: 경로 필수** — WSL `/home`(=`\\wsl.localhost\…` UNC)에서는 MSBuild/cmd 가 `MSB8066` 로 실패.
- **WSL_INTEROP**: 비대화형 SSH엔 unset → Windows .exe 실행 실패(`accept4 failed 110`).
  win-build-wsl.sh 가 `/run/WSL/*_interop` 중 살아있는 소켓 자동 탐지. **사용자 대화형 WSL 터미널이 하나 열려 있어야** 소켓이 삶.
- **glad = jinja2 필요**: Windows Python `C:\Program Files\Python312\python.exe` 에 `pip install --user jinja2` (win-build-wsl.sh `deps` 스텝이 함).
- **정적 링크**: `av.exe` 는 SDL3 정적 + **정적 CRT(/MT)** → 별도 DLL/VC++ 재배포판 **불필요**(시스템 DLL만). 단일 파일 배포.
- **C:\Windows 설치는 관리자(UAC)**: 직접 cp 는 Permission denied. `Start-Process -Verb RunAs` 로 상승 복사
  (`script/win-install.sh` 패턴 = scratchpad에 있음). 데스크톱 UAC 승인 필요.
- **원격 장시간 빌드 실행법**: `run_in_background`+heredoc-stdin 은 stdin 미전달로 실패 → **스크립트 파일 scp → nohup 분리실행 → 원격 log 폴링**.
