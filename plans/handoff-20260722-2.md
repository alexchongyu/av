## 2. 전체 CLI 레퍼런스 (헤드리스 = CI/스크립트용)

```bash
# 지표 (CSV 14열: file,width,height,psnr_db,psnr_r,psnr_g,psnr_b,psnr_y,ssim,flip,mse,mae,max_error,msigned)
av --metrics A.png B.png
av --pair --metrics dirA/frame001.png dirB              # 시퀀스 전체 + 요약(stderr)
av --pair --metrics dirA/f.png dirB --fail-psnr 40      # CI 게이트: 위반 시 exit 10
av --metrics A B --format json                          # JSON(frames[]+summary{aggregates,gate})
av --pair --metrics A dirB --fail-flip 0.1 --format junit   # JUnit XML

# diff 이미지 내보내기 (GUI 없이 PNG)
av --diff-out d.png --diff-mode signed --amplify 8 A B
av --diff-out d.png --diff-mode flip A B                # magma 히트맵
av --diff-out d.png --diff-mode signed --sbs A B        # A│Δ│B 합성(3×폭)

# 결함 검사 (float/HDR)
av --validate img.hdr                                   # NaN/Inf 있으면 exit 8

# 색 룩 (GUI 표시)
av --lut look.cube A.png B.png                          # ' 로 토글
av --cdl grade.cdl A.png B.png
```
**exit code**: 0 성공 / 3 인자오류 / 4 디코드실패 / 5 크기불일치 / 6·7 diff-out 계산·쓰기 / 8 validate NaN·Inf / 10 CI 게이트 FAIL.

**주요 GUI 키**: Ctrl+0 FLIP, Ctrl+1 Signed, Ctrl+7 SSIM (그 외 Ctrl+2..9 기존 diff), `,` 블링크(`<`/`>` 간격), `/` 결함오버레이, `'` LUT 토글, `i` Image Info(PSNR 자동). 전체는 앱 내 Hotkey Reference(Ctrl+Shift+H).

| ODC | **GtG 응답·오차트레이스**(오버슛%/정착) · GtG 응답매트릭스(pass/fail) · 시간축 픽셀맵. (**Signed 맵✅이 오버슛/언더슛 뷰의 일부**) |
| LIRC/GIRC | 방사/행열 드룹 프로파일 · 블록/라인무라 심 검출 · 비균일도 그레이스윕 |
| ECC | 서브픽셀 결함 검출+커버리지맵(ISO-13406-2) · 에너지보존/헤일로 · 비트뎁스/밴딩. (**validator✅가 결함검출의 일부**) |

**DDI top-6 추천**: ① 비균일도 메트릭 팩 ② 서브픽셀 결함 검출 ③ GtG 응답 분석 ④ Luma/Chroma 분리 PSNR ⑤ 컬러메트리 프로브(모든 색 IP 토대) ⑥ 서브픽셀 A/B 정합.
> 공통 토대: **컬러메트리 코어(RGB→XYZ→u'v'/CCT/ΔE)**를 만들면 CTC/CGM/Demura 색 기능이 전부 열림. 대부분 `metrics_cli`(헤드리스 CSV+exit) / `chart_export`(라인컷/플롯) / SSIM·FLIP 히트맵 파이프라인 재사용.
