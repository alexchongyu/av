# Plan: av (Alex's Image Viewer) 전체 구현

## Context

av-spec.typ에 정의된 크로스 플랫폼 이미지 뷰어/비교 도구를 처음부터 구현한다.
현재 소스 코드가 전혀 없으며, 모든 파일을 새로 생성해야 한다.
macOS 우선 (Apple Silicon), Linux/Windows도 지원.

## 핵심 기술 결정

| 항목 | 결정 | 비고 |
|------|------|------|
| GLSL 버전 | `#version 150` (macOS 호환) | 런타임에 prepend |
| glad2 | v2.0.8, `SOURCE_SUBDIR cmake` | Python3+Jinja2 확인됨 |
| ImGui | docking branch, 커스텀 STATIC 타겟 | 7개 .cpp 수동 등록 |
| SDL3 | release-3.2.0, 정적 링크 | `SDL_SHARED OFF` |
| lcms2 | OPTIONAL (`AV_HAS_LCMS2` 가드) | 없어도 빌드됨 |
| 셰이더 | `shader_sources.h`에 constexpr 임베딩 | 파일 로딩 없음 |
| ImGui GL로더 | `IMGUI_IMPL_OPENGL_LOADER_CUSTOM` | glad 사용 |

## 생성할 파일 (19개)

```
CMakeLists.txt                     # 빌드 시스템 (FetchContent)
src/main.cpp                       # SDL3/OpenGL/ImGui 초기화 + 메인 루프
src/app.h                          # AppState, CliOptions 타입 정의
src/app.cpp                        # CLI 파싱, 키보드 핸들링
src/shader_sources.h               # GLSL vertex/fragment 셰이더 소스
src/image_loader.h / .cpp          # stb_image 로딩, LRU 8개 캐시
src/gl_texture.h / .cpp            # 텍스처 업로드, ShaderProgram, ScreenQuad
src/viewport.h / .cpp              # pan/zoom/fit 변환 계산
src/diff_engine.h / .cpp           # GPU diff (shader), CPU SSIM (jthread)
src/stb_impl.cpp                   # STB_IMAGE_IMPLEMENTATION
src/ui/main_window.h / .cpp        # ImGui dockspace + 메뉴바
src/ui/image_panel.h / .cpp        # 이미지 렌더링 (FBO → ImGui::Image)
src/ui/statusbar.h / .cpp          # 상태 표시줄
```

## 팀 구성 (5 에이전트, worktree 격리)

| # | 에이전트 | 담당 파일 | 의존성 |
|---|----------|-----------|--------|
| 1 | **build-and-types** | `CMakeLists.txt`, `src/app.h`, `src/shader_sources.h`, `src/stb_impl.cpp` | 없음 (기반) |
| 2 | **core-modules** | `src/viewport.h/.cpp`, `src/image_loader.h/.cpp`, `src/app.cpp` | app.h 인터페이스 |
| 3 | **gl-rendering** | `src/gl_texture.h/.cpp`, `src/diff_engine.h/.cpp` | app.h, shader_sources.h |
| 4 | **ui-layer** | `src/ui/main_window.h/.cpp`, `src/ui/image_panel.h/.cpp`, `src/ui/statusbar.h/.cpp` | app.h, gl_texture.h, viewport.h |
| 5 | **main-entry** | `src/main.cpp` | 모든 헤더 |

**병렬화 전략**: 공유 헤더 인터페이스의 정확한 내용을 각 에이전트 프롬프트에 포함하여, 타입 불일치 없이 독립 작업. 각 에이전트는 worktree에서 파일 생성 후 메인에 병합.

## 빌드 및 검증

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(sysctl -n hw.ncpu)
./build/av                         # 빈 윈도우 + ImGui UI
./build/av image.png               # 단일 이미지 표시
./build/av a.png b.png             # Side-by-side 비교
./build/av --diff-mode=abs a.png b.png  # Diff 모드
```

### 완료 기준
- `cmake --build build` 오류 없이 완료
- `./build/av` 실행 시 SDL3 윈도우 + ImGui dockspace 표시
- 이미지 인자로 실행 시 이미지 로딩 및 표시
- H/J/K/L 패닝, +/- 줌 동작
- 두 이미지 side-by-side + diff 모드 전환
